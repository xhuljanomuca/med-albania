# Delivery roadmap
Phase 1: authentication, registration, profile, initial grants, bilingual UI (this repository).
Phase 2: course catalog, localized content, chapter navigation, instructor editing, degree/profession eligibility.
Phase 3: assessments, question banks, attempt policies, pass/fail at >=70%, progression locks.
Phase 4: payments, certificates, accreditation approval and verification, analytics.
Phase 5: community, announcements, notifications, support, webinars, reporting, operational security.
